# Fintech Care Plus

Sistema de controle financeiro desenvolvido para a atividade final da FIAP.

## Tecnologias utilizadas

### Backend
- Java
- Spring Boot
- Oracle Database
- JPA / Hibernate

### Frontend
- ReactJS
- React Router
- JavaScript

---

## Funcionalidades

- Cadastro de usuários
- Cadastro de gastos
- Cadastro de receitas
- Consulta de dados
- Integração Frontend e Backend
- API REST

---

## Como executar o Backend

1. Abrir o projeto no IntelliJ
2. Executar a classe:

FintechBackendApplication

3. Backend disponível em:

http://localhost:8080

---

## Como executar o Frontend

1. Abrir o projeto fintech-front no VS Code
2. Executar:

npm install

3. Depois executar:

npm start

4. Frontend disponível em:

http://localhost:3000
